Developer Quick Reference

📘 Complete Beginner's Architecture & Customization Cheat Sheet

1. Change School Name & Bus Fleet (`fleetBuses`)

Search for const fleetBuses in the script to edit bus numbers, license plates (TN-20-AB-4512), driver names, and phone numbers.

2. Edit Default Stops & Students (`getDefaultStops()`)

Each stop object holds name, timeLabel, lat/lng coordinates, and a roster array of students.

3. How Live State & Storage Work (`renderApp()`)

Every button updates a JavaScript state variable, saves to localStorage, and calls renderApp() to refresh all maps, cards, and tables at once.

4. Connect Real Backend GPS Later (Firebase / Supabase)

When you are ready for multi-phone cloud sync, replace localStorage.setItem with a free Firebase Realtime Database listener.
